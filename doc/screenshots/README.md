# Screenshots Directory

Save your screenshot images in this folder with the following filenames:

1. `dashboard_desktop.png` - Windows/Desktop Dashboard View
2. `ram_desktop.png` - Windows/Desktop RAM Diagnostics View
3. `dashboard_mobile.png` - Mobile (Android/iOS) Dashboard View
4. `ram_mobile.png` - Mobile (Android/iOS) RAM Diagnostics View

Once saved here, run:
```bash
git add doc/screenshots/
git commit -m "docs: Add screenshot images"
git push origin master
```
